# Подход — дневник тренировок

Приложение для iPhone и других устройств: программа с добавлением тренировок, рабочие подходы, таймер отдыха, история, графики и резервные копии.

## Редактирование программы

- В разделе «Программа» выберите день и нажмите «Добавить упражнение».
- Нажмите существующее упражнение, чтобы изменить название, мышечную группу, подходы, диапазон повторов, отдых и заметку по технике.
- Для удаления нажмите «Удалить из программы» в редакторе и подтвердите действие. История, рекорды и начатая тренировка не меняются.
- Можно очистить день полностью и заполнить заново; запуск пустого дня недоступен. Максимум — 30 упражнений в день.
- Изменения сохраняются на устройстве и включаются в резервную копию. Новая программа используется при следующем запуске тренировки.

## Запись тренировки

С обзора можно начать следующий день программы или продолжить незавершённое занятие. После отметки подхода приложение подставляет вес в следующий пустой подход и запускает отдых. На телефоне список над названием упражнения позволяет сразу перейти к нужному движению. Кнопка «Завершить» сохраняет отмеченные подходы даже при частично выполненной программе.

Для обновления замените файлы оболочки содержимым архива, включая изображение `barbell.svg`, и откройте приложение с подключением к интернету. Кэш оболочки — `podhod-shell-v7`. Ключ localStorage и формат резервной копии версии 1 сохранены.

## Публикация на GitHub Pages

1. Создайте репозиторий, например `podhod`. Для GitHub Free нужен публичный репозиторий.
2. Загрузите содержимое этой папки в корень репозитория: `index.html` должен находиться рядом с этим README, а не внутри дополнительной папки. ZIP предварительно распакуйте.
3. В Settings → Pages выберите Deploy from a branch → main → /(root), затем Save. Если основная ветка называется иначе, выберите её.
4. Дождитесь успешного развёртывания. GitHub покажет точный адрес сайта в Settings → Pages.
5. На iPhone откройте адрес в Safari → Поделиться → На экран Домой.

Все пути относительные: приложение работает и по адресу /podhod/, и в корне пользовательского сайта. Сборка, npm, сервер и API-ключи не нужны.

## Данные

Дневник хранится только в браузере на устройстве. Личные записи не загружаются в репозиторий. При смене адреса сначала экспортируйте JSON-копию на старом сайте, затем восстановите её на новом через настройки. Автоматической синхронизации нет.

GitHub Pages публикует интерфейс приложения для всех, кто знает ссылку. Это не перенос приватной авторизации Sites.

Таймер отсчитывает время после сворачивания; фоновый звук на iPhone не гарантируется. Для гантелей записывайте вес одной гантели, для упражнений со своим весом — 0 кг или дополнительное отягощение.
