# Подход — дневник тренировок

Приложение для iPhone и других устройств: программа на три дня, рабочие подходы, таймер отдыха, история, графики и резервные копии.

## Публикация на GitHub Pages

1. Создайте репозиторий, например `podhod`. Для GitHub Free нужен публичный репозиторий.
2. Загрузите содержимое этой папки в корень репозитория: `index.html` должен находиться рядом с этим README, а не внутри дополнительной папки. ZIP предварительно распакуйте.
3. В Settings → Pages выберите Deploy from a branch → main → /(root), затем Save. Если основная ветка называется иначе, выберите её.
4. Дождитесь успешного развёртывания. GitHub покажет точный адрес сайта в Settings → Pages.
5. На iPhone откройте адрес в Safari → Поделиться → На экран Домой.

Все пути относительные: приложение работает и по адресу /podhod/, и в корне пользовательского сайта. Сборка, npm, сервер и API-ключи не нужны.

## Данные

Дневник хранится только в браузере на устройстве. Личные записи не загружаются в репозиторий. При смене адреса сначала экспортируйте JSON-копию на старом сайте, затем восстановите её на новом через настройки. Автоматической синхронизации нет.

GitHub Pages публикует интерфейс приложения для всех, кто знает ссылку. Это не перенос приватной авторизации Sites.

Таймер отсчитывает время после сворачивания; фоновый звук на iPhone не гарантируется. Для гантелей записывайте вес одной гантели, для упражнений со своим весом — 0 кг или дополнительное отягощение.
